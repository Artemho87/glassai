# Очки ИИ: помощник со зрением и переводчик для Ray-Ban Meta Gen 2

Приложение для Android. Что умеет:

- **ИИ-помощник со зрением.** Нажимаешь «Спросить» и говоришь вопрос. Очки делают кадр, ИИ (Claude или Gemini) отвечает голосом прямо в динамики очков.
- **ИИ-переводчик.** Слушает собеседника (например, по-тайски) и шепчет тебе перевод на русский. Свой ответ говоришь по-русски, и перевод звучит громко из телефона плюс крупно показывается на экране.
- **Штатная съёмка не меняется.** Приложение занимает камеру только на 2–3 секунды во время вопроса. «Hey Meta, take a photo», кнопка на дужке и видео работают как раньше.

Кнопки «Спросить», «Переводчик» и «Стоп» есть в уведомлении, так что ими можно пользоваться с заблокированного экрана.

---

## Шаг 1. Получить APK

APK собирается автоматически на GitHub: вкладка **Actions** → «Собрать APK». Через 5–8 минут файл появляется в разделе **Releases** → `GlassAI.apk`.

1. Открой на телефоне страницу репозитория → **Releases** → **GlassAI.apk** и скачай файл.
2. Открой скачанный файл. Если Android спросит «Разрешить установку из этого источника?», нажми **Настройки**, включи переключатель и вернись назад.
3. Нажми **Установить**. Если появится Google Play Защита, выбери «Всё равно установить» (приложение твоё, его нет в магазине).

## Шаг 2. Включить режим разработчика в Meta AI

Без этого очки не пустят стороннее приложение.

1. Открой приложение **Meta AI** → **Настройки** (Settings) → **О приложении** (App Info).
2. Нажми **5 раз подряд** на номер версии (App version). Появится переключатель **Developer Mode**.
3. Включи его и нажми **Enable**.
4. Очки должны быть надеты и подключены. Если Meta AI предложит обновить ПО очков, обнови.

## Шаг 3. Подключить приложение к очкам

1. Открой **Очки ИИ** и разреши всё, что спросит Android: устройства поблизости, микрофон, уведомления.
2. Нажми **Подключить**. Откроется Meta AI: включи переключатель «Unverified app», если он есть, и нажми **Connect**. Тебя вернёт обратно.
3. Нажми **Разрешить камеру** → в Meta AI выбери **Always allow** (Разрешать всегда).
4. В строке состояния должно стать: «подключено ✅ · Камера: разрешена ✅».

## Шаг 4. Ключ ИИ (на выбор)

- **OpenRouter — по умолчанию.** Зайди на openrouter.ai → Keys → **Create Key**, скопируй ключ `sk-or-…` и вставь. Модель по умолчанию `google/gemini-3.1-flash-lite`: быстрая и копеечная, понимает фото.

Внизу экрана, раздел **«Настройки ИИ»**. Вставь ключ одного из сервисов:

- **Gemini — бесплатно в пределах лимитов.** Зайди на aistudio.google.com → **Get API key** → **Create API key**, скопируй ключ (начинается с `AIza`) и вставь в поле.
- **Claude — платно, но копейки.** Зайди на console.anthropic.com → Billing (пополни на $5) → **API Keys** → **Create Key**, скопируй ключ `sk-ant-…` и вставь. Подписка Claude Pro к API не относится, оплата отдельная.

## Как пользоваться

- **Вопрос:** нажми «🎤 Спросить», дождись короткого сигнала и спроси: «Что это?», «Переведи меню», «Сколько тут калорий?». Если промолчать, ИИ опишет, что перед тобой.
- **Переводчик:** выбери языки «Собеседник → Я» и нажми «Включить переводчик». Для своего ответа нажми «🗣 Мой ответ».

## Если что-то не работает

| Что видишь | Что сделать |
|---|---|
| «Очки не найдены» / «Очки не ответили» | Надень очки, проверь Bluetooth и что Developer Mode включён (он может слететь после обновления Meta AI) |
| «Нет доступа к камере очков» | Нажми «Разрешить камеру» ещё раз |
| «Ошибка ИИ (401)» | Неверный ключ: вставь заново, без пробелов |
| «Ошибка ИИ (404)» | Неверное имя модели: верни `claude-haiku-5-5` или `gemini-flash-latest` |
| Не слышит голос | Говори после сигнала. Если микрофон очков не подхватился, приложение слушает телефон: держи его ближе |
| Нет распознавания тайского | Google → Настройки → Голосовой ввод → Языки → добавь тайский |
